TactileKinesis Glove

3D Visualizer · Hand gesture interpretation concept

Technology for more accessible communication

This project explores a smart glove concept using an ESP32 and flex sensors to detect finger bending, with a browser-based visualizer showing sensor values and a 3D hand model.
