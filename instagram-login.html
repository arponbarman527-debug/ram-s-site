Meta Setup Instructions

Follow these exact steps in your Meta for Developers Console to make this button functional:

  2. Create a new App and select "Consumer" or "Build Connected Experiences".

  4. In Instagram Basic Display Settings, click Create New App.
  5. Set the OAuth Redirect URI to:
